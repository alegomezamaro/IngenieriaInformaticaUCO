10. Una vez ensamblado el PC, en el arranque y en general, ¿Qué significa 1
”beep” en el arranque y cuál puede ser la causa? ¿Y 2 ”beeps”? ¿Y 5 ”beeps”?

El significado del "beep" puede cambiar dependiendo la duración de los mismos.
Si escuchamos 1 corto, significa que todo está correcto. Si escuchamos 1 contínuo, se debe
a un suministro eléctrico inadecuado de la línea eléctrica o bien de la fuente de
alimentación. Si escuchamos 1 largo pero que se corta, puede ser que alguna ranura de
memoria RAM esté defectuosa o bien la memoria esté conectada incorrectamente.
Si escuchamos 2, ocurre lo mismo. Si escuchamos uno largo y uno corto, puede ser un
posible error en la placa o en la propia BIOS. Si escuchamos 2 cortos, es un error en la
paridad de memoria.
Por último si escuchamos 5 "beeps", significa que el procesador o la tarjeta gráfica se
encuentran bloqueados.

Cuestiones práctica 2 CESI:
1. ¿Qué es una máquina virtual? Diferénciala en su definición de un contenedor de software como
Docker.

Una máquina virtual es un entorno de software que emula un sistema completo de hardware físico,
permitiendo ejecutar un sistema operativo y aplicaciones de forma independiente y asilado del
sistema operativo base. Una VM incluye un sistema operativo invitado, su propio kernel, y un
conjunto completo de recursos virtualizados (CPU, memoria, almacenamiento).
Máquina virtual vs Docker:
Máquina virtual: Requiere un hipervisor para gestionar múltiples VMs y virtualiza todo el
hardware. Es más pesada en términos de recursos.
Contenedor (Docker): Comparte el kernel del sistema operativo anfitrión y virtualiza a nivel de
sistema operativo. Es más ligera y eficiente en recursos, pero está más limitada al entorno del
anfitrión. Proporciona una capa adicional de abstracción y automatización de virtualización de
aplicaciones en múltiples sistemas operativos.

2. ¿Como definirías el Hipervisor?

El hipervisor es un software o firmware que permite la creación y gestión de máquinas virtuales,
proporcionando a cada VM acceso aislado y controlado a los recursos físicos del hardware
subyacente.

Virtualización completa, de hardware o nativa: El hipervisor simula un hardware
suficiente para permitir un sistema operativo no adaptado que es ejecutado de forma
aislada.
- Virtualización parcial o paravirtualización: El hipervisor ofrece un interfaz especial
para acceder a los recursos. Esto hace que el sistema operativo tenga que
responder a llamadas especiales o “hypercalls”.
- Emulación: El hipervisor imita por medio de software una arquitectura al completo.
Así puede hacer creer a los programas y sistemas operativos diseñados para una
arquitectura en específico que son ejecutados sobre ella

3. ¿Cual es la gran diferencia entre QEMU y Virtualbox como herramientas de virtualización?

QEMU: Es un emulador que simula completamente el hardware, lo que permite ejecutar sistemas
operativos de distintas arquitecturas. Puede usarse con o sin KVM (Kernel-based Virtual Machine)
para acelerar la virtualización.
VirtualBox: Es una herramienta de virtualización optimizada para entornos de escritorio. No
soporta emulación completa de hardware como QEMU y depende del hardware del sistema
anfitrión.

4. ¿En qué se caracteriza una distribución de GNU/Linux con una política de publicación de rolling
release? ¿Qué problema podríamos encontrar en servidores?

Rolling Release: Se caracteriza por proporcionar actualizaciones continuas y frecuentes sin
necesidad de versiones mayores. Los paquetes se actualizan a medida que están disponibles.
Problemas en servidores: Estas actualizaciones constantes pueden introducir bugs, inestabilidad o
problemas de compatibilidad en entornos de producción, donde la estabilidad es crucial.

5. ¿En qué consiste el particionado de disco en un sistema GNU/Linux?

El particionado de disco consiste en dividir un disco físico en secciones lógicas (particiones),
permitiendo organizar y gestionar mejor el sistema de archivos. En GNU/Linux, las particiones
comunes incluyen:
• / (root): Sistema principal.
• /home: Directorios personales de los usuarios.
• /var: Archivos temporales y logs.
• Partición de intercambio (swap): Espacio en disco para memoria virtual.

6. ¿Qué utilidad puede tener el montar en una partición independiente la carpeta /home?

Montar /home en una partición independiente permite:
• Preservar los datos personales de los usuarios al reinstalar o actualizar el sistema operativo.
• Mejorar la seguridad y estabilidad al evitar que los usuarios llenen el espacio del sistema
principal.
• Facilitar backups y migraciones.

7. Ordéname de más a menos seguras estas conexiones:

SSH con usuario y contraseña, telnet, SSH con claveSSH.
De mayor a menor seguridad:
1. SSH con clave: Usa claves públicas/privadas, lo que reduce el riesgo frente a ataques de fuerza
bruta.
2. SSH con usuario y contraseña: Más seguro que Telnet, pero susceptible a ataques de fuerza
bruta si la contraseña es débil.
3. Telnet: Inseguro porque transmite datos en texto plano, incluyendo contraseñas.


8. A qué obedecen las siglas LAMP cuando hablamos de instalar las herramientas necesarias para
un servidor web.
Cuando hablamos de instalar las herramientas necesarias para un servidor web, las siglas LAMP se
refieren a:
• Linux: Sistema operativo.
• Apache: Servidor web.
• MySQL: Sistema de gestión de bases de datos.
• PHP/Python: Lenguaje de programación para aplicaciones web dinámicas.

9. ¿Cual es la forma más rápida y directa de comprobar que nuestro servidor web puede ejecutar
código PHP?

La forma más rápida y directa de comprobar que nuestro servidor web puede ejecutar código PHP:
1. Crear un archivo llamado info.php en la raíz del servidor web con el siguiente contenido
<?php phpinfo(); ?>
2. Abrir el archivo en un navegador web apuntando a la dirección del servidor, por ejemplo:
http://localhost/info.php
Si el archivo muestra información detallada sobre PHP, significa que el servidor puede ejecutar
código PHP correctamente. 

10-¿Cuál es la diferencia entre e VMWare y su diferencia con Player?

VirtualBox es una solución gratuita y de código abierto, que permite crear y ejecutar
máquinas virtuales. También permite ejecutar varias máquinas al mismo tiempo. VMWare
Player por otro lado estaría más limitado ya que solo puede ejecutar máquinas virtuales que
hayan sido creadas con VMWare Workstation. Workstation necesita una licencia de pago
para ser utilizado, pero tiene mejores prestaciones que VirtualBox, lo que permite trabajar
con máquinas más complejas.

11: ¿Qué es LVM? ¿Qué ventaja tiene para un servidor de gama baja?

Es una implementación de gestor de volúmenes lógicos para Linux. Las ventajas que tiene
para un servidor de gama baja es que nos permite relocalizar el espacio libre con facilidad
en caso de que un volumen lógico se quede sin tamaño.

12 ¿Qué diferencia existe entre telnet y ssh?

Con SSH se realiza una conexión segura al servidor, sin embargo con Telnet se expone
toda la información que intercambiamos con el servidor. Es por esto que es recomendable
usar SSH frente a Telnet


12: ¿Qué instalamos con el servicio LAMP?

El servicio LAMP es una plataforma compuesta por:
- Linux - El sistema operativo base
- Apache - El servidor.
- MySQL - El servidor de base de datos.
- PHP - Lenguaje de programación utilizado.
El acrónimo está formado por las iniciales de cada una de las herramientas utilizadas.
